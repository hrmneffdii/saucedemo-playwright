# BUG-003: All products show the same image on the inventory page for `problem_user`

| Field | Details |
|---|---|
| **Severity** | Medium |
| **Priority** | P3 |
| **Status** | New |
| **Type** | UI / Visual |
| **Component** | Inventory page / Product images |
| **Reported by** | Herman Effendi |
| **Date reported** | 2026-10-28 |
| **Environment** | Brave Browser 156.1.98.60 , Ubuntu 24.04 , https://www.saucedemo.com |
| **Test account** | `problem_user` / `secret_sauce` |
| **Reproducibility** | [5] out of [5] attempts |

## Summary
After logging in as `problem_user`, all 6 products on the inventory page display the same image, even though the product names and prices are different.

## Preconditions
- The user is logged in as `problem_user` and is on the inventory page.

## Steps to Reproduce
1. Open https://www.saucedemo.com.
2. Log in as `problem_user` / `secret_sauce`.
3. Look at the image next to each of the 6 products.
4. (Control) Log out, log in as `standard_user` / `secret_sauce`, and compare the images.
5. (Optional) Open DevTools, inspect each product image, and compare the `src` attributes.

## Expected Result
Each product shows its own image that matches its name (for example, a backpack image for Sauce Labs Backpack), as seen with `standard_user`.

## Actual Result
All 6 products show the same image. In DevTools, the `src` attribute is identical for all images (or the unique values are fewer than 6). 

## Evidence
- Screenshot as `problem_user`: `evidence/bug-003-problem-user.png`
- Screenshot as `standard_user` (control): `evidence/bug-003-standard-user.png`
- Automated test: `tests/known-bugs.spec.ts`, "BUG-003: all products use the same image" (marked with `test.fail()` while the bug exists). The control test for `standard_user` (unique images) passes.

## Impact
- **User:** customers cannot tell products apart visually and may pick the wrong item. Trust in the store decreases.
- **Business:** can lower conversion and increase returns. Core functionality still works.
- **Severity rationale:** Medium. Information is misleading, but checkout is not blocked and names and prices remain correct.
- **Priority rationale:** P3. It should be fixed, but it can be scheduled after functional blockers such as BUG-001 and BUG-004.

## Possible Cause (hypothesis, not confirmed)
The image source may be resolved from a single shared value instead of per product. Black-box observation only.

## Suggested Fix
Bind each product to its own image source and add an automated check that all image sources on the page are unique.

## Workaround
Use the product name and price to identify items.

## Retest Criteria
- Six distinct images are displayed and each matches its product.
- The automated test for BUG-003 fails after the fix, which signals that `test.fail()` should be removed.
